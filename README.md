# E-commerce- 🛍️

A small demo storefront for **Aam Saman** — built and pushed to GitHub entirely by **Muse**.

## What's inside

| File | What it does |
|---|---|
| `index.html` | Page structure: header, hero, product grid, cart drawer |
| `styles.css` | Dark modern theme, responsive layout |
| `app.js` | Product rendering, working cart (saved in `localStorage`), demo checkout |

## How this repo was made

1. Ahmed created the empty repo on GitHub (apps can't create repos — GitHub rule).
2. Muse wrote all the code on its own machine.
3. Muse pushed everything here in one commit via the GitHub API.

## Try it

Open `index.html` in a browser (or serve the folder with any static server).
Add products to the cart, change quantities, hit checkout.

*Demo prices are in PKR. No real orders — this is a workflow test.*
